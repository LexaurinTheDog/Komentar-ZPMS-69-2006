# Komentář k zákonu č. 69/2006 Sb., o provádění mezinárodních sankcí

Otevřený komentář k zákonu o provádění mezinárodních sankcí — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; oblasti uplatňování sankcí, výjimky a ochranná bariéra, oznamovací povinnost, nakládání se sankcionovaným majetkem, řízení před Finančním analytickým úřadem, správa a prodej majetku, dozor, mezinárodní spolupráce, poplatek za správu majetku, donucovací pokuty a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2006-00069_2026-01-01`.
